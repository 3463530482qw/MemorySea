# Lua 5.5.0（vendored 脚本引擎）

- **版本**：Lua 5.5.0（2025-12-15 发布）
- **来源**：Lua.org / PUC-Rio 官方发行版，与上游源码保持一致
- **许可证**：MIT（见 lua.h 文件末尾的 Copyright Notice）
- **纳入日期**：2026-08-02

## 与上游的差异

无。本目录保持纯上游源码，未来语法魔改一律通过独立 patch 应用，
**不要直接修改本目录内的源码**，否则上游更新时将无法合并。

## 魔改计划（未来，未实施）

  （如 `if→如果`、`while→当` 等），同时同步 `luaX_token2str()` 的报错字符串
- 注意：Lua 5.5 新增了 `global` 保留字（兼容模式开关），魔改时留意

## 目录说明

- `l*.c` / `l*.h`：Lua 库源码（32 个 .c + 头文件），`gcc` 以 C 语言编译
- **未纳入** `lua.c`、`luac.c`：这两个是独立 CLI 程序（解释器/编译器），
  自带 `main()` 会与主程序冲突，需要时单独构建

## 编译方式

[build.py](../build.py) 已接入：`gcc -c lua/*.c` → `build/lua/*.o`，
再随主程序一起链接（Lua 头文件带 `extern "C"` 保护，g++ 链接无障碍）。
